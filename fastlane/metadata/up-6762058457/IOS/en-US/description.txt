Codexex keeps Codex quota and OpenAI API monitoring together on iPhone and iPad.

Sign in with ChatGPT to see your 5-hour and weekly allowance, reset times and provider-reported Codex credits. Accounts that report only a weekly limit get a weekly view. Codex credits are shown separately from API dollars.

Connect a standard OpenAI API key to verify API access, or an organization Admin key for usage and cost reports. Optional prepaid balance monitoring uses a separate billing sign-in.

Add quota and API balance widgets to your Home Screen. Start a Live Activity for subscription quota on your Lock Screen and Dynamic Island. Readings come from app refreshes; iOS decides when background updates run. Widgets show the last observation and mark older data as stale.

Native onboarding, clear account settings, light and dark appearances, larger text support, preview data and local usage history make it easy to get started.

Saved API keys and subscription tokens use this device's Keychain. Provider requests run on your device. The optional background wake service receives delivery details, not your OpenAI credentials or quota values. Codexex monitors usage without generating content.
